# React Personal Blog Site

A personal blog site built with React components, demonstrating how to pass data using props.

## Components
- **Header**: Displays the name of the blog. Connected to `App`.
- **About**: Displays an image and a short description about the blog. Connected to `App`.
- **ArticleList**: A container for rendering a list of `Article` components. Connected to `App` (parent) and `Article` (child).
- **Article**: Displays a single blog post's title, date, and preview text. Connected to `ArticleList`.

## How to run the project
1. Ensure you have Node.js installed.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
4. Open the provided local server link in your browser to view the blog.
